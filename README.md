# AURELIA // 21·09

A self-contained cinematic experience page — a single static HTML file with inline styles, inline SVG assets, and Google Fonts (Cormorant Garamond + Inter). No build step, no dependencies.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Served by GitHub Pages from the root of `main`. The live page is at:

`https://dreamcoder08.github.io/aurelia21/`
