# AURELIA21 — Professional Redesign

## Objective
Restructure the AURELIA 21 single-file page into a multi-file, no-build project with a real design token system, modular JS, automated Playwright/axe tests, and elite responsive/a11y execution — without changing copy, tone, or visual identity.

## Problem / Why
The page was a single monolithic `index.html` (inline CSS, inline JS, base64-embedded images) with no automated tests, no responsive/a11y guarantees, and no maintainable structure. Spec: `docs/superpowers/specs/2026-09-21-aurelia21-professional-design.md`. Plan: `docs/superpowers/plans/2026-09-21-aurelia21-professional-redesign.md`.

## Scope
Native HTML/CSS/JS served as-is by GitHub Pages (zero build). Split inline `<style>` into 5 tokenized CSS files, split 2 inline `<script>` blocks into 5 ES modules + entry, extract base64 JPEGs/favicon to files, add Playwright + axe-core test harness across 4 viewports, harden responsive/a11y, document, then publish.

## Constraints
- Zero build: GitHub Pages serves `index.html` from `main` at `/`; `bun install` is dev-only.
- Spanish copy, emotional content, and visual identity (dark `#070706` + gold, Cormorant Garamond + Inter) unchanged.
- Conventional Commits, no AI attribution, no Co-Authored-By.
- No raw hex color literals outside `tokens.css`; no repeated `font-family` outside `tokens.css`.
- Final `index.html` ≤ 70KB.
- Tests run over HTTP only (`tests/serve.mjs` + `webServer`, baseURL `http://localhost:4173`).
- Viewports: phone 390×844, tablet 768×1024, laptop 1280×800, desktop 1440×900.
- axe acceptance: zero `serious`/`critical` violations in locked AND unlocked states.
- Delivery: work-unit commits on branch `feat/professional-redesign`; merge to `main` + push only in T9 (publish pre-authorized by user).

## TDD mode
Enabled, source: existing plan convention (every task writes a failing/characterization test first, implements, then verifies green). Runner: `bun run test` (Playwright, `tests/playwright.config.js`). Bun is the standing tooling requirement for this project — never npm/npx (user instruction, 2026-09-22).
